# Breast Cancer Prediction App

A **machine learning web application** built with **Streamlit** to predict whether a tumor is **Benign (B)** or **Malignant (M)** using the **Kaggle Breast Cancer Wisconsin dataset**.

---

This project applies a **Logistic Regression** model trained on selected features from the dataset. The model achieves a **94% accuracy** on the test set. The Streamlit app allows users to input tumor characteristics and get instant predictions.

---

Check out the deployed app here:  
[Streamlit App](https://breastcancerpredictor-e5apphnvpuuu8ra4fuybdgr.streamlit.app/)

---

- Source: [Kaggle - Breast Cancer Wisconsin Diagnostic](https://www.kaggle.com/datasets/uciml/breast-cancer-wisconsin-data)
- Target: Diagnosis (`B` = Benign, `M` = Malignant)
- Features used:
  - `radius_mean`
  - `texture_mean`
  - `perimeter_mean`
  - `area_mean`
  - `smoothness_mean`
